# Databases — Week 1 Teacher Notes

## Suggested schedule

The session runs from **12:00 to 16:00**, including a 30-minute lunch and two 10-minute breaks. Times include questions and checks for understanding.

| Time | Activity | Pause and check |
|---|---|---|
| 12:00–12:25 | Introduction to databases (section 1) | Ask learners to name a row and a column in a contact list. |
| 12:25–13:05 | Connect, explore, and understand the database (sections 2.2–2.6) | Everyone can find the `task` table and the task with `id = 18`. |
| 13:05–13:15 | Short break | |
| 13:15–14:00 | SQL basics and `SELECT` practice (sections 3.1–3.7) | Pause after the first successful `SELECT`. |
| 14:00–14:30 | Lunch | |
| 14:30–15:10 | `INSERT` and `UPDATE` (sections 3.8–3.9) | Record inserted IDs and pause before changing data. |
| 15:10–15:20 | Short break | |
| 15:20–15:40 | `DELETE` and table creation (sections 3.10–3.11) | Check the target rows with `SELECT` before deleting. |
| 15:40–16:00 | Combined exercise, takeaways, and safety review (sections 3.13–3.15) | Ask learners to explain what a primary key and `WHERE` do. |

**Teaching priorities:**

- In section 2.4, demonstrate creating the separate database; participants continue using the downloaded database. For section 2.5, discuss questions 1, 3, and 6.
- In section 3.7, work on questions 1, 3, 7, 9, and 11. Leave the other questions, including the bonus questions, for independent practice.
- In sections 3.8 and 3.9, do INSERT exercises 1, 5, and 6 and the corresponding UPDATE exercises 1, 5, and 6. Then do all three DELETE exercises in section 3.10. Record the inserted IDs and use the described SELECT checks before and after changes. Demonstrate section 3.11; leave section 3.12 for independent practice.
- In section 3.13, do tasks 1–6 in class; leave tasks 7–8 and the remaining exercises for independent practice. Review the safety rules before the session ends.

Participants should install DBeaver and download the sample database before the session (allow approximately 15–30 minutes separately). The glossary and optional VS Code instructions are reference material. Setup problems, longer discussions, or the lunch and breaks may leave less time for practice; move additional exercises to independent practice if needed rather than rushing the first successful query or safety checks.
